# Flappy Bird Game with Advanced Features

This is a Flappy Bird-inspired game that includes the following advanced features:

1. **Login System**: Players can sign up, log in, and save their progress securely.
2. **Shop System**: Players can purchase new character sprites or powerups using in-game currency.
3. **Score System**: Tracks and saves scores for each user.
4. **Leaderboard**: Displays top players based on scores.
5. **Character Selection**: Players can select from multiple bird characters.

## Features Breakdown

- **Game Core**: Basic Flappy Bird mechanics, including obstacle avoidance and scoring.
- **Login System**: A lightweight database or JSON files for managing user accounts.
- **Shop System**: Unlockable items (new bird skins, powerups, etc.).
- **Score System**: Saves scores locally and within the login system database.

## Installation

### Prerequisites
- Python 3.x
- `pygame` library (Install using `pip install pygame`)

### Instructions
1. Clone the repository:
   ```bash
   git clone https://github.com/ApicX/flappy.git
   ```
2. Navigate to the project directory:
   ```bash
   cd flappy
   ```
3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
4. Run the Game:
   ```bash
   python main.py
   ```
